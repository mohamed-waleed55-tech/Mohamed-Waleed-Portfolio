# Front Design Skill

## 1. Purpose & Usage

Use this skill to design the portfolio frontend as a premium product
experience for recruiters and engineering hiring managers. Its purpose
is to make the candidate's engineering value immediately understandable,
then use the interface itself as proof of frontend quality. Prioritize
clarity, credibility, project presentation, and conversion to Work, CV,
GitHub, LinkedIn, or Contact actions.

## 2. Visual Direction

Follow a **dark premium engineering** direction: black as the
foundation, blue for technology and structure, and yellow only for
high-value actions. Use precise typography, strong hierarchy, generous
whitespace, restrained borders, subtle technical grids, architectural
lines, real product screenshots, and meaningful micro-interactions. The
interface should feel sophisticated, intentional, modern, and engineered
rather than decorative.

## 3. Constraints

Do not create a generic AI portfolio or template-like layout. Avoid
excessive gradients, neon, glassmorphism, giant typography, floating
blobs, random 3D objects, gaming/cyberpunk aesthetics, skill percentage
bars, fake statistics, fake testimonials, unnecessary cards, excessive
animation, animated cursors, particle effects, or decorative elements
that compete with the work. Never invent project data, achievements,
metrics, clients, technologies, or experience.

## 4. What Makes It Unique

The differentiator is **turning engineering thinking into visual
language**. Treat the portfolio like a real software product: structure
sections like a system, present projects like product case studies, use
technical metadata and architectural visual cues sparingly, and make
interactions demonstrate precision rather than spectacle. The result
should make visitors think: **"This engineer builds serious products."**
